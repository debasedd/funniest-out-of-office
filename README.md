A tiny program for the [The Funniest Out-of-Office](https://make.fun/c/u-kreutzx-the-funniest-out-of-office-054815cf) bounty on [make.fun](https://make.fun).

It writes one line to `/output/entry.txt` — a one-line out-of-office auto-reply, the funniest I could make it:

> I'm on holiday until Monday. My inbox is watched by my fridge, which only answers emails about snacks and has accepted two meetings.

Run it with:

```sh
python3 main.py
```
